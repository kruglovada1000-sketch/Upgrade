# JARVIS // KODA

Наша надстройка над открытым проектом `adewaskar/jarvis`.

Задача: превратить JARVIS из демонстрационного голосового ассистента в рабочий интерфейс для `ohrana.tech`, GitHub и `Upgrade`, не смешивая исходники сайта с инструментами разработки.

## Как устроено

Мы не копируем upstream вручную. GitHub Actions при каждой сборке:

1. клонирует свежий `adewaskar/jarvis`;
2. накладывает `PROJECT-CONTEXT.md` на системные промпты bridge/direct;
3. меняет локальное название пакета на `jarvis-koda`;
4. добавляет наш boot-log и заголовок `J.A.R.V.I.S. // KODA`;
5. сохраняет upstream MIT-лицензию и отдельный notice;
6. выполняет `npm ci` и `npm run build`;
7. только после успешной сборки выдаёт ZIP-артефакт `jarvis-koda-ready`.

## Почему так

Так мы можем получать исправления оригинального JARVIS, не теряя наши правила. Если upstream обновится, следующая сборка берёт свежую основу и сразу проверяет совместимость. Если API/структура изменилась и наша надстройка больше не подходит, workflow падает до выдачи готового архива — сломанная версия не считается готовой.

## Что уже адаптировано

- русский язык по умолчанию;
- рабочий позывной «Лейтенант КОДА»;
- контекст `ohrana.tech` и `Upgrade`;
- безопасный процесс GitHub-правок;
- правила sitemap/canonical/404/SEO;
- правила мобильной и светлой/тёмной темы;
- запрет придумывать фирменный шеврон;
- разделение GitHub `main` и фактически опубликованного хостинга;
- безопасный режим действий.
