# Upgrade

`Upgrade` — отдельная техническая мастерская для развития сайтов, в первую очередь `ohrana.tech`.

Задача репозитория — хранить не сам сайт, а инструменты, правила, AI-skills и шаблоны автоматических проверок. Это позволяет улучшать сайт, не засоряя его исходники чужими большими репозиториями.

## Что уже входит

- `rules/OHRANA-TECH.md` — правила работы именно с `ohrana.tech`.
- `skills/seo/SKILL.md` — наш workflow технического SEO-аудита.
- `skills/site-qa/SKILL.md` — проверка интерфейса, мобильной версии и регрессий.
- `templates/github-actions/links.yml` — шаблон проверки битых ссылок через Lychee.
- `templates/github-actions/lighthouse.yml` — шаблон Lighthouse-проверки производительности и SEO.
- `docs/TOOLS.md` — список внешних инструментов и зачем они нам нужны.

## Принципы

1. Не копировать целиком огромные чужие репозитории без необходимости.
2. Использовать только нужные части и собственные адаптированные правила.
3. Не менять рабочий сайт ради эксперимента без контрольной точки.
4. Сначала проверка, потом внедрение в `ohrana.tech`.
5. Автоматические проверки сначала работают как мониторинг и не блокируют публикацию сайта.

## Основные внешние источники

- ECC — набор практик и skills для AI-разработки.
- Google Lighthouse CI — автоматическая проверка качества веб-страниц.
- Lychee — поиск битых ссылок.
- Chrome DevTools MCP — браузерная диагностика для AI-агентов.

`Upgrade` не является форком этих проектов и не содержит их полных исходников.
