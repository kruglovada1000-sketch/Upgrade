# Инструменты Upgrade

Ниже — внешние проекты, на которых основана наша система улучшения сайта. Мы не копируем их целиком в `Upgrade`: используем их как отдельные инструменты и адаптируем только нужные идеи/конфигурации.

## 1. ECC

Repository: `affaan-m/ECC`

Назначение: большая библиотека практик, skills и agent-workflows для AI-разработки.

Для `ohrana.tech` полезны в первую очередь идеи из направлений:

- SEO;
- code review;
- frontend patterns;
- security;
- testing/QA;
- research-first workflow.

Мы не переносим сотни skills. Вместо этого поддерживаем собственные короткие skills в `Upgrade/skills`, рассчитанные на реальный стек сайта.

Лицензия исходного проекта: MIT.

## 2. Google Lighthouse CI

Repository: `GoogleChrome/lighthouse-ci`

Назначение:

- Performance;
- SEO-аудиты Lighthouse;
- Accessibility;
- Best Practices;
- обнаружение регрессий после изменений.

Для нашего статического сайта можно запускать Lighthouse без сборки проекта.

Лицензия: Apache-2.0.

## 3. Lychee

Repositories: `lycheeverse/lychee` и `lycheeverse/lychee-action`

Назначение:

- поиск битых ссылок;
- проверка ссылок в HTML/Markdown;
- автоматический запуск через GitHub Actions.

В `templates/github-actions/links.yml` лежит наш стартовый шаблон. На первом этапе он не блокирует публикацию сайта: сначала собираем реальные проблемы и очищаем ложные срабатывания.

## 4. Chrome DevTools MCP

Repository: `ChromeDevTools/chrome-devtools-mcp`

Назначение: подключение браузерной диагностики к совместимому AI-agent окружению.

Полезно для:

- Console errors;
- Network/404;
- DOM;
- эмуляции мобильных устройств;
- диагностики производительности;
- проверки поведения интерфейса.

Это отдельный инструмент; его исходный код не нужно копировать в `Upgrade`.

Лицензия: Apache-2.0.

## Платность

Базовые перечисленные open-source проекты можно использовать без покупки лицензии. Отдельные сторонние облачные сервисы, хостинги или коммерческие надстройки могут иметь собственную оплату, но они не являются обязательной частью нашей схемы.

## Порядок внедрения

1. Собственные правила и skills — уже хранятся в `Upgrade`.
2. Lychee — подключить к `ohrana.tech` как мягкий мониторинг ссылок.
3. Lighthouse — подключить как мягкий мониторинг качества.
4. После устранения накопленных проблем постепенно сделать часть проверок обязательной.
5. Browser MCP подключать только в среде, где AI-agent действительно умеет использовать MCP.
